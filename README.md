## The roast

> My phone's battery health is 87%, which it proves daily by dying at 4pm like a Victorian child sent to bed without supper.

122 characters — one original line roasting the phone that dies every afternoon.

## How to run

Requires Node 22.18+ (runs TypeScript directly, no install needed):

```sh
node main.ts
```

This writes the roast to `/output/entry.txt`. To write elsewhere, set `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/roast-gadget-out node main.ts
```

The program validates the line in code (1–200 characters, not only whitespace) and writes it with no trailing newline.
